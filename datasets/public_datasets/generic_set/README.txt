20 public DXF technical drawings

Source: ECCV 2026 CAD Challenge Data, Hugging Face
https://huggingface.co/datasets/jingwei-xu-00/eccv2026-cad-challenge-data

This bundle contains test_public samples 000000–000019 from test_public/techdraw/dxf. These are multi-view technical drawing exports derived from Thingiverse CAD assets, not manufacturing-ready laser-cut profiles and not RFQ/quote records.

The dataset card reports mixed upstream licenses (including attribution, share-alike, non-commercial, and public-domain/CC0 licenses). The repository's source_attribution.csv records attribution by Thingiverse source but the public sample IDs are anonymized and do not map back to individual source IDs. Therefore the upstream license for each file in this small selection cannot be verified from the public metadata. Treat this bundle as a research/inspection sample; do not redistribute or use commercially until the source licenses are individually resolved.

See source_attribution.csv and the dataset card's License And Attribution section for provenance notes. manifest.csv provides source path, URL, byte size, and SHA-256 for each DXF.
